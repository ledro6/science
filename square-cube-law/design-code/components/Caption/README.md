# Caption

Вшитый субтитр: группа из 1–3 слов, каждое слово проявляется подъёмом и размытием в момент, когда диктор его произносит.

- Стиль `caption` (66 px, 600, трекинг −0.02em), цвет `ink` текущей сцены; на стыке сцен цвет берётся от сцены, чей фон на экране.
- Центр группы по x = 500 px (не 540: справа колонка кнопок), базовая линия `caption-y` (1400 px).
- Группа рвётся на знаке препинания, после 16 символов или 3 слов.
- Вход слова: 0,6 с, подъём 26 px, размытие 12 → 0, за 60 мс до звука. Уход группы: вверх на 34 px и прозрачность за 0,26 с — «лентой», не налезая на следующую.
- Цветом слова не выделяем: активное слово отличается только тем, что оно уже появилось.

Что даёт потребитель: тайминги слов из TTS (WordBoundary) или из распознавания речи.
