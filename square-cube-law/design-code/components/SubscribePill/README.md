# SubscribePill

Кнопка-пилюля «Подписаться» на финальной карточке — единственный «интерфейсный» элемент в кадре.

- Заливка `ink`, текст `on-pill`, стиль 40 px / 600, высота 128 px, радиус `radius-pill`, ширина по тексту + 2 × 64 px.
- Появляется пружиной на слове «Подпишись», мягко пульсирует (масштаб 1 → 1,02, период 1,6 с), на последнем слове призыва «нажимается»: масштаб 0,96 и тонкое кольцо `hairline` расходится от краёв.
- Используется в TikTok, Reels и VK. В YouTube Shorts не рисуется: у площадки своя кнопка подписки, а пилюля попала бы под интерфейс.
