# SafeZones

Общая безопасная зона мастер-кадра 1080×1920 поверх интерфейсов площадок: что угодно важное — внутри белой рамки.

- Мастер-зона: x 80–940, y 250–1440 (токены `safezone`). Это пересечение зон TikTok, Reels, Shorts и VK Клипов.
- Полоса 3:4 (y 240–1680) — то, что видно в сетке профиля TikTok и Instagram: в неё ставится текст обложки.
- Значения наблюдаемые; перед публикацией сверяйте с актуальным шаблоном площадки.
