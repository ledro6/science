# Callout

Выноска от точки на 3D-объекте к подписи: так мы называем части объекта, не перекрывая его.

- Точка-якорь 5 px и линия 2 px цветом `hairline`; якорь проецируется из 3D каждый кадр, поэтому линия «прилипает» к объекту на орбите.
- Подпись — две строки: первая `label` цветом `ink` («Площадь сечения»), вторая `footnote` цветом `ink-muted` («прочность ∝ L²»).
- Порядок появления: точка за 0,25 с, линия рисуется от объекта к тексту за 0,4 с, затем текст blur-rise.
- Выноски появляются только когда объект остановился; не больше двух в кадре.
