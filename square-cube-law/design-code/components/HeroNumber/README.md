# HeroNumber

Одна огромная цифра с маленькой подписью: главный носитель смысла в кадре.

- Цифра — `hero-number` (320 px, 700, −0.045em), подпись — `label` (42 px, 500) цветом `ink-muted`, под цифрой, по её левому краю, с отступом `space-2`.
- Знак «×» тем же кеглем; пробелы-разделители тысяч обычные («×1 000 000»), цифры табличные, чтобы счётчик не прыгал.
- Вход: счёт от 0 по expo за 1,2 с, масштаб 1,15 → 1, размытие 20 → 0. Подпись — через 0,25 с.
- Одна цифра на кадр. Если нужно сравнение двух чисел — две строки друг под другом и тонкие полосы длиной пропорционально значению.
