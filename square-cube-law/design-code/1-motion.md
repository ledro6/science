# Движение и 3D

Все параметры взяты из движка пилота (`square-cube-law/apple/engine.mjs`), так что их можно переносить в следующие выпуски без подбора.

## Кривые

| Имя | Значение | Где |
| --- | --- | --- |
| apple | cubic-bezier(0.28, 0.11, 0.32, 1) | Появление текста и объектов: быстрый старт, долгий хвост |
| ease | cubic-bezier(0.25, 0.1, 0.25, 1) | Финальное затухание ролика |
| standard | cubic-bezier(0.4, 0, 0.2, 1) | Энергичный акцент, рост счётчиков |
| exit | cubic-bezier(0.4, 0, 1, 1) | Уход текста и сцены: быстрее, чем вход |
| in-out | cubic-bezier(0.65, 0, 0.35, 1) | Exploded view: разлёт и сборка деталей |
| spring | 1 − (1 + 7t)·e^(−7t) | Рост объектов: пружина без перелёта |
| expo | 1 − 2^(−10t) | Счётчики от 0 до значения |

## Текст: blur-rise

| Параметр | Заголовок | Субтитр |
| --- | --- | --- |
| Длительность входа | 0,75 с | 0,60 с |
| Подъём | 40 px → 0 | 26 px → 0 |
| Размытие | 12 → 0 px, заканчивается на 70% времени | 12 → 0 px |
| Масштаб | 1,04 → 1 | 1,04 → 1 |
| Уход | прозрачность и размытие до 8 px за 0,35 с, без сдвига | вверх на 34 px за 0,26 с, «лентой» |
| Stagger | 75 мс между словами (≤ 5 слов) | по таймингам речи: слово появляется за 60 мс до звука |

Огромная цифра «приземляется»: масштаб 1,15 → 1, размытие 20 → 0 px, трекинг стягивается до −0.045em, счёт от 0 по expo за 1,2 с. Подпись приходит через 0,25 с.

## Сцены и переходы

- Вход новой сцены: её фон проявляется за 0,22 с поверх фона предыдущей, содержимое — через 0,12 с, с размытием 14 → 0 px и масштабом 1,035 → 1 за 0,7 с.
- Уход: прозрачность и размытие 10 px за 0,35 с.
- Финал ролика: всё уходит в чёрный за 1,2 с.
- Запрещено: кросс-диссолвы длиннее 0,5 с, вращающиеся и кубические переходы, глитч, вспышки.

## 3D-приёмы серии

| Приём | Как | Пример из пилота |
| --- | --- | --- |
| Из темноты | Ключевой свет разгорается за 1,5 с, контровой — раньше | Муравей в первом кадре |
| Скользящий блик | Источник света проезжает по грани за 1,5–2 с | Алюминиевый куб в хуке |
| Exploded view | Детали расходятся вдоль осей за 1,6 с, stagger 40–80 мс от центра | Куб 2×2×2 и 3×3×3 |
| Срез | Плоскость отсечения проходит за 1,2–1,6 с, срез светлее материала | Кость как кристалл чипа |
| Макро-проезд | fov 15°, камера скользит над поверхностью | Сечение кости |
| Распад | 1 000–2 000 частиц InstancedMesh, плоскость отрыва идёт по телу | Муравей в финале |
| Match-cut формы | Новая форма проявляется поверх старой в той же позиции | Ноги слона → колонны |

## Свет и материалы

- Тонмаппинг ACES Filmic, экспозиция 1,0, вывод sRGB.
- Чёрная сцена: заполнение 0,55, ключ 2,6, контровые 3,2 и 2,4 — объект освещён на 60%, остальное тонет в темноте.
- Светлая сцена: заполнение 1,15, ключ 2,2, контровые 1,2 и 0,9, тень пола 16%.
- Стекло без transmission: белая оболочка 14% непрозрачности плюс тонкие рёбра 85%. Так оно рендерится в 2 раза быстрее и читается на обоих фонах.

## Производительность

Рендер программный (SwiftShader в headless Chromium): держите кадр ≤ 450 мс. Не используйте env-карты, transmission, постобработку и дополнительные проходы рендера; повторяющиеся объекты — через InstancedMesh. Пилот: ~0,15–0,4 с на кадр, полный ролик в 60 fps на 4 потоках — около 15 минут вместе со звуком.
