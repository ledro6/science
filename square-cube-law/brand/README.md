# Логотип и баннеры канала L³

Рендер: `node capture.js` (все) или `node capture.js avatar,vk-cover` → `out/*.png`. Имя серии — константа `NAME` в `brand.mjs`.

Знак — алюминиевый куб, от которого отслаивается стеклянная грань: площадь (L²) отделяется от объёма (L³). 3D-версия рендерится теми же материалами и светом, что и ролик; плоская — для размеров меньше 64 px.

| Файл | Размер | Где использовать |
| --- | --- | --- |
| `avatar.png` | 1080×1080 | Аватар: TikTok, Instagram, YouTube, VK, Telegram (знак в центральных 70% — безопасно для круга) |
| `avatar-paper.png` | 1080×1080 | Светлый вариант аватара |
| `logo-mark-3d-black.png` / `-paper` / `-transparent` | 2048×2048 | Знак для заставок, презентаций, мерча |
| `logo-mark-flat-white.png` / `-ink.png` | 1024×1024, прозрачный фон | Фавикон, водяной знак, мелкие размеры |
| `logo-lockup-black.png` / `-paper.png` | 3000×1000 | Знак + имя + дескриптор |
| `youtube-banner.png` | 2560×1440 | Шапка YouTube; всё важное в центральной зоне 1546×423 |
| `youtube-watermark.png` | 150×150 | Водяной знак YouTube («Брендинг») |
| `youtube-thumbnail-ep1.png` | 1280×720 | Превью длинного выпуска № 1 (шаблон) |
| `vk-cover.png` | 1920×768 | Обложка сообщества VK |
| `telegram-header.png` | 1280×720 | Закреплённый первый пост канала Telegram |
| `cover-vertical-ep1.png` | 1080×1920 | Обложка пилота для TikTok, Reels, VK Клипов (текст в полосе 3:4) |
| `ig-highlight-*.png` | 1080×1920 | Обложки «Актуального» Instagram |

## L³ (актуальное)

| Файл | Размер | Где использовать |
| --- | --- | --- |
| `yt-avatar.png` | 800×800 | Аватар YouTube |
| `tt-avatar.png` / `tt-avatar-paper.png` | 1080×1080 | Аватар TikTok (тёмный / светлый) |
| `yt-banner-l3.png` | 2560×1440 | Шапка YouTube, важное в зоне 1546×423 |
| `tt-pin-1..3.png` | 1080×1920 ×3 | Обложки трёх закреплённых роликов TikTok: в сетке профиля складываются в одну шапку (`tt-pin-preview.png`) |
| `ep<N>-tiktok-cover.png` | 1080×1920 (файл 2160×3840) | Обложка выпуска для TikTok |
| `ep<N>-shorts-cover.png` | 1080×1920 (файл 2160×3840) | Обложка выпуска для YouTube Shorts |

Новый выпуск — запись в `EPISODES` в `brand.mjs`.

YouTube — только Shorts: горизонтальные ассеты (`youtube-thumbnail-ep1.png`) остались от ранней версии и больше не используются.
