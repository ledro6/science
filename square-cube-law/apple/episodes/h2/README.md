# h2 · Шестой этаж, часть 2

Оригинальный художественный вымысел, продолжение h1. Начало сразу показывает последствие предыдущего финала: чужая тень проходит в квартиру соседа. Варежка даёт личное доказательство, мать объясняет своё исчезновение, лифт переносит героя к исходному открытию дверей. Последний вопрос ребёнка делает спутницу героя новой загадкой.

Голос: ru-RU-DmitryNeural, −4%. Все реплики новые. Словесные тайминги и исходные MP3 находятся в `build/voice`. Геометрия и графитовая сцена основаны на h1, новые модели находятся в `scenes/details.mjs`. Плавные наезды и панорамы используют quintic smoothstep, как h1 v3. Музыка воспроизводит одобренный h1 мотив и инструменты с новыми точками нарастания и паузами. Это собственная синтезированная композиция без сторонних семплов.

Из `square-cube-law/apple/`:

```bash
PYTHONPATH=/workspace/artifacts/python-deps python3 -u /workspace/artifacts/l3-h1/tts-retry.py "$PWD/episodes/h2"
EP=h2 node capture.js sfx
OPENBLAS_NUM_THREADS=1 PYTHONPATH=/workspace/artifacts/python-deps python3 episodes/h2/mix.py --build episodes/h2/build --duck -19
python3 ../tiktok/srt.py episodes/h2
```

Стандартный `render_ep.sh` переписывает mix.wav общей музыкой, поэтому после него нужно снова выполнить команду собственного микса и переподключить звук. Для чистой сборки координатору следует сразу использовать `mix.py` вместо общего `audio.py`, сохранив параметры финального кодирования 1440×2560, 60 fps, CRF 16.

Обложка: `cover.json`, `hero.mjs`, история 02. Раскадровка: `STORYBOARD.md`. Контрольные кадры и контактный лист: `stills/`. Сведения о финальном просмотре, прослушивании и декодировании заполняются координатором после сборки; контроль кадров сам по себе не подтверждает эти проверки.
