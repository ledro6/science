# Бриф: Apple-версия ролика «Закон квадрата–куба» (1080×1920, 60 fps, ≈92 с)

Заказчик отверг прежние версии как «похожие на всё в интернете». Нужен визуальный язык **keynote-презентаций Apple**:
- **Строгий монохром.** Чёрный фон с белым (#FFF) текстом или светлый фон (#F5F5F7) с чёрным (#1D1D1F) текстом.
  Серый #86868B для подписей. **Никаких цветных градиентов и цветного текста.** Единственный акцент —
  системный красный #FF453A, только в моменты «перелома» (и то точечно).
- **Максимум необычной 3D-графики в сочетании с 2D.** 3D-объекты в «продуктовой» подаче: керамика, алюминий, графит,
  чёрный глянец, стеклянные оболочки с тонкими рёбрами. Exploded view (разлёт деталей и сборка), срезы clipping-плоскостью,
  медленные орбиты камеры, макро-проезды, «объект появляется из темноты», свет скользит по грани.
  Поверх — 2D-типографика и тонкие выноски-callouts (линия 2 px от точки на объекте к подписи, якорь пересчитывается из 3D каждый кадр).
- **Огромная цифра + маленькая подпись** (соотношение 6:1–8:1), ≤ 7 слов в заголовке, один кадр — одна мысль.
- **Движение медленное и «дорогое»:** без отскоков и перелётов (пружины — critical damping `eSpring`), основная кривая
  `eApple`, уходы `eIn` короче входов. Ни одного движения короче 0.4 с, кроме монтажных ударов.
- Обязательно прочитай **`../tiktok/APPLE_STYLE.md`** — стайлгайд с параметрами (раздел 8 — идеи приёмов; бери лучшие и придумывай свои,
  но в монохроме: «площадь» показываем стеклом/контуром/светом, «объём» — цельным материалом/массой; вместо цветов — материалы и свет).

## Код
- `engine.mjs` — движок (НЕ редактировать). Прочитай целиком: `makeStage({bg:'black'|'white'})` (сцена, камера fov 26, ключ+заполнение+2 контровых света,
  пол с мягкой тенью; `stage.ink`/`stage.sub` — цвета текста под фон), `orbit`, `project` (3D→экран), `MAT.*`, `roundedBox`, `glassEdges`, `shadowsOn`,
  2D: `atext` (фирменный blur-rise), `atextWords`, `acount`, `line`, `dot`, `callout`; тайминг `P`, `FIO`, `C`, `E`, `Wd`, `WdE`, `rng`, кривые.
- `models.mjs` — общие модели (можно использовать, НЕ редактировать): `makeAnt` (pose buckle/walk/drop), `makeElephant` (flap/squat/trunk),
  `makeMouse` (wag/squash), `makeFlea` (crouch), `makeBone(len, th)`, `rod`. Свои модели/детали делай внутри своего файла сцены.
- Сцена = файл `scenes/<id>.mjs`:
```js
import { defineScene, makeStage, orbit, project, atext, P, Wd, THREE, MAT /* … */ } from '../engine.mjs';
import { makeAnt } from '../models.mjs';
defineScene('cube', {
  setup(s) { const stage = makeStage({ bg: 'white' }); /* построить все объекты один раз */ return { stage /*, …*/ }; },
  update(t, s, st) { /* выставить ВСЕ трансформации/материалы/камеру из t (чистая функция времени) */ },
  draw2d(t, s, st) { /* типографика и выноски поверх 3D; цвет текста: st.stage.ink / st.stage.sub */ },
  sfx(add, s) { add(Wd('c2', 'площадь'), 'chime', .6); },
});
```
- `update` и `draw2d` — **чистые функции времени** (кадры рендерятся параллельно в любом порядке): каждый кадр задавай позицию/поворот/масштаб/
  видимость/opacity ВСЕХ объектов заново; никакого `+=`; случайность только `rng(seed)`.
- Фон сцены един на всю сцену (белый или чёрный — указан ниже). Подсцены внутри сцены меняй через уход/появление объектов и камеру.
- Переходы между сценами и **субтитры (y≈1400) делает движок** — ничего не ставь в зону y ∈ [1330, 1480] и ниже 1540.
  Безопасная зона: x ∈ [80, 940], y ∈ [250, 1300]. Заголовки ≤ 900 px шириной.
- **Бюджет скорости:** рендер программный (SwiftShader). Держи кадр ≲ 450 мс: не используй `transmission`, env-карты, постпроцессинг,
  дополнительные проходы рендера и лишние источники с тенями; геометрия умеренная (сферы ≤ 48 сегментов). Сотни мелких мешей — через `InstancedMesh`.
- Тайминги слов: `../tiktok/build/timeline_readable.txt` (`слово@секунда`). Синхронизируй по `Wd(...)`.
- Звуки `sfx` (типы): pop, tick, click, chime, whoosh, swell, rise, riser (ставить ЗА 1.5 с до акцента), impact, bloom, shimmer, thud, crack, splash, boing, fall.
  В стиле Apple звуков мало и они мягкие: низкий whoosh/thump на появление объекта, мягкий click на сборку, без «мультяшных» эффектов.

## Проверка
`node capture.js stills 1.2,2.5,4.0 <префикс> only=<id>` → `stills/<префикс>_t<время>.png` (грузится только твоя сцена — быстро).
Ошибки печатаются как `PAGE ERROR` / `CONSOLE` / `RENDER ERROR` — их быть не должно.
Смотри кадры каждые ~0.7 с по своей сцене (контакт-лист через Pillow: 6 кадров в ряд по 270×480), исправляй до чистого результата.
Замерь время кадра (`time node capture.js stills <10 моментов> perf only=<id>`, вычти ~5 с запуска).
Финальный рендер видео не запускай.
