# Бриф: вертикальный ролик «Закон квадрата–куба»

Формат TikTok / Reels / Shorts: 1080×1920, 60 fps, ≈92 с, русская озвучка (уже готова).
Цель — удержание внимания: **что-то меняется на экране каждые 1–2 секунды**, визуал строго
синхронизирован со словами диктора.

## Стиль: Apple keynote
- Тёмный фон (рисует движок), крупная жирная типографика `"Inter Display"` (700–800), много воздуха.
- **Текст и объекты появляются из размытия**: blur → резкость + прозрачность → 1 + лёгкий подъём/масштаб.
  Для текста используйте `atext` / `atextWords` / `acount` (уже делают blur-in и blur-out через `out`).
  Для графики: `g.filter = 'blur(Npx)'` с убыванием N, либо масштаб 0.9→1 с `espr`/`eexp`.
- Кривые: `eexp` (expo out — по умолчанию для появлений), `espr` (пружина с лёгким перелётом),
  `eio` для перемещений. Никаких линейных движений.
- Акценты: градиентный текст (`grad: [COL.area, COL.vol]`), стеклянные плашки `glass(...)`,
  плавные зумы камеры `withCam`, «удар» камеры `punch` на ключевых словах, `shake` для «хруста».
- Палитра (`COL`): `ink` (текст), `dim`, `faint`, `cube`, `area` (янтарный = площадь, L²),
  `vol` (голубой = объём, L³), `red`, `heat`, `green`. Площадь всегда янтарная, объём — всегда голубой.
- Минимализм: на экране одновременно 1 главная идея, максимум 2–3 элемента.

## Раскладка кадра (`LAYOUT` в engine.js)
- Выше y=250 и ниже y=1560 — интерфейс платформы, ничего важного там не рисуем.
- Справа ~140 px заняты кнопками платформы: центр композиции `LAYOUT.cx = 520`, держите важное в x ∈ [70, 940].
- Графика сцены — в зоне y ∈ [300, 1220] (центр `LAYOUT.stageY = 760`).
- **Субтитры рисует движок** на y≈1370 — не ставьте туда ничего.
- Вверху (y≈250) движок рисует стеклянную «пилюлю» с названием главы, если в сцене задан `chapter`.
- Заголовки — не шире ~900 px (при 1080 ширине кадра). Проверяйте на стоп-кадрах.

## Как устроен код
- `engine.js` — движок и все хелперы (НЕ редактировать; если очень нужно — опишите в отчёте).
  Прочитайте его целиком перед работой: там 2D-примитивы (`txt`, `line`, `arrow`, `circle`, `ellipse`, `glow`),
  3D-кубы (`cam`, `drawCubes`, `drawWire`, `frontTiles`, `droppedCubes`, `corners`, `proj`),
  силуэты (`drawAnt` с `buckle/crack`, `drawElephant` с `flap/legCol/squat`, `drawMouse`, `drawFlea`, `drawBone`, `drawHouse`),
  тайминг (`P`, `FIO`, `C(key)`, `E(key)`, `Wd(key, слово, n)` — точное начало слова, `WdE` — конец слова), `rng(seed)`.
- Каждая сцена — свой файл `scenes/<id>.js`, **обёрнутый в IIFE** `(() => { ... })();` (все скрипты делят
  одну глобальную область — без обёртки будут конфликты имён):

```js
(() => {
  defineScene('cube', {
    chapter: 'КУБИК',                // текст пилюли сверху (или не задавать)
    draw(t, s) { /* t — абсолютное время, s = {id,start,end} */ },
    sfx(add, s) { add(Wd('c2', 'площадь'), 'chime', .8, 1.0); /* (время, тип, громкость, высота) */ },
  });
})();
```
- `draw` должна быть **чистой функцией времени** (кадры рендерятся параллельно, в любом порядке):
  никакого состояния между кадрами, случайность только через `rng(seed)`.
- Переходы между сценами (blur + масштаб) делает движок; в начале/конце сцены своё затухание не нужно,
  но внутри сцены «подсцены» меняйте через blur-out старого и blur-in нового.
- Тайминги реплик и каждого слова: `build/timeline_readable.txt` (формат `слово@секунда`), полные данные в `build/timeline.json`.
  Синхронизируйте по `Wd(...)`, а не по «на глаз» секундам.
- Типы звуков для `sfx` (их синтезирует audio.py): `pop`, `tick`, `click`, `chime`, `whoosh`, `swell`, `rise`,
  `riser` (нарастание ~1.5 с, ставить ЗА 1.5 с до акцента), `impact` (глубокий кинематографичный удар), `bloom`,
  `shimmer`, `thud`, `crack`, `splash`, `boing`, `fall`. Звук на каждое появление ключевого элемента,
  но без каши: ≥ 0.12 с между событиями одной сцены, тихие `tick`/`pop` для мелочей.

## Проверка
```
node capture.js stills 1.2,2.5,4.0 <префикс>   # → build/stills/<префикс>_t<время>.png
```
Ошибки страницы печатаются в консоль (`PAGE ERROR` / `RENDER ERROR`) — у вас их быть не должно.
Смотрите кадры (Read по PNG; для экономии можно склеить контакт-лист через Pillow, 360×640 на кадр)
**каждые ~0.7 с по всей сцене** + моменты переходов, правьте до чистого результата:
ничего не обрезано, не наезжает на субтитры, текст читается, всё в безопасной зоне.
Финальный рендер видео не запускайте — его сделает координатор.
